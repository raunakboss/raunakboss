### 🚘 [ANPR — Automatic Number Plate Recognition](https://github.com/raunakboss/ANPR_Project)

Reads Indian licence plates from vehicle photos: a custom-trained **YOLO26n** detector finds the plate, then a multi-variant **EasyOCR** pipeline (CLAHE, adaptive/Otsu thresholding, sharpening) reads it — with two-line plate reconstruction and structure-aware correction for Indian registration formats. Ships as a **Streamlit** dashboard.

| Precision | Recall | mAP@50 | mAP@50-95 |
|:---:|:---:|:---:|:---:|
| **0.975** | **0.957** | **0.989** | **0.803** |

<sub>Held-out test set · 164 images · trained on a Tesla T4</sub>
